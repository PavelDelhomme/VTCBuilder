# Scripts d'Outils

Ce dossier contient les scripts Python utilitaires pour le développement.

## Scripts disponibles

- **divide_block_preview.py** - Division du fichier BlockPreview
- **extract_all_cases.py** - Extraction de tous les cases
- **extract_and_divide.py** - Extraction et division
- **extract_cases.py** - Extraction des cases
- **extract_cases_safe.py** - Extraction sécurisée des cases
- **split_block_preview.py** - Division de BlockPreview

## Usage

Ces scripts sont des outils de développement pour la refactorisation du code.
Ils ne doivent pas être exécutés en production.
