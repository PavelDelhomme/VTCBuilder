# Tests Unitaires Backend

Les tests unitaires vérifient que chaque modèle, vue, sérialiseur ou utilitaire fonctionne isolément.

## Structure

```
unit/
├── models/        # Tests des modèles Django
├── views/         # Tests des vues/ViewSets
├── serializers/   # Tests des sérialiseurs DRF
└── utils/         # Tests des utilitaires
```
